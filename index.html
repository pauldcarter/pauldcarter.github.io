Technologies

Technologies used across the projects above, selected to suit each project's requirements.

Front end

React · Next.js · vanilla JS Vite and Tailwind on the larger applications; plain JavaScript where a build step is unnecessary.

Back end

Python · Django · Node Django for full server-rendered applications, Python at the edge, and client-side only where no server is required.

Data

Postgres · SQLite · key-value PostGIS for geospatial queries, SQLite for smaller workloads, and Durable Objects for real-time state.

Hosting

Cloudflare · Vercel · GitHub Pages · GCP Edge runtimes and static hosting for most projects; a virtual machine where full control of the environment is required.
