RunTracker

RunTracker presents parkrun results as visualised progress over time. Results are imported in a single step, then displayed in interactive charts that can be shared via read-only links.

Visit live ↗

Bookmarklet import & shareable views

Parkrun provides no public API, so RunTracker uses a bookmarklet: the user opens their results page and clicks once to import the data. Progress is then presented as interactive charts, and a signed link provides a read-only view to others without requiring an account.

Key features

  • One-click bookmarklet import straight from a parkrun results page — no manual data entry.
  • Interactive charts of times, positions and progress across every event and runner.
  • Read-only sharing via signed links, allowing others to view results without registering.
  • Multi-runner support, allowing several runners' results to be tracked alongside one another.
  • Served entirely from a single Cloudflare Worker with a colocated database.
