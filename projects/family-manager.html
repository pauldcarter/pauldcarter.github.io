Family Manager

An application for organising family life. It installs to the home screen and continues to work without a network connection, as it requires no server, no account and no external dependencies.

Visit live ↗

Installs like a native app, works offline

The application deliberately omits a back end, a database host and any sign-in. The PWA app shell and on-device storage provide all functionality, resulting in no running costs, no transmission of personal data, and operation independent of network availability.

Key features

  • Add-to-home-screen PWA — installs like a native app on phones and desktops.
  • Fully offline-capable: the app shell and data live on the device.
  • No account or sign-in required.
  • Family data remains on the device and is never transmitted.
  • Static hosting constitutes the entire infrastructure, so there are no running costs.
