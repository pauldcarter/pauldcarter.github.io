Golf Coach

A golf coaching application in which a coach curates a visual knowledge base of technique — foundations, symptoms and fixes — and the AI is restricted to recommending only from that approved library.

In development

GUI-managed knowledge driving the coach

An administrator edits a mind-map graph of foundations → symptoms → resources, and the coach diagnoses a player's technique and prescribes only fixes drawn from that curated library. All advice is therefore traceable to an identified coaching source.

Key features

  • Visual mind-map editor for the knowledge base — drag, connect and auto-layout, hand-built in SVG/canvas.
  • A structured graph of foundations → symptoms → resources encoding established coaching knowledge.
  • A logic/AI coach that diagnoses technique from symptoms and prescribes only approved fixes.
  • No third-party dependencies: vanilla JavaScript in the browser and plain Node http on the server.
  • Atomic write-and-rename saves to a JSON file store, providing safe persistence without a database.
