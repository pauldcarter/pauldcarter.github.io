Every game written twice, in two languages

Each game exists in two versions built to the same design, so the pair can be read side by side to see how the same idea takes shape in a different language. The games are playable; the comparison is the point.

Key features

  • Every game built twice, in two languages, for side-by-side comparison.
  • Plays instantly in the browser — no download, no install, no account.
  • Works on any device with a browser, including locked-down school Chromebooks.
  • Free to play, with nothing to buy and no adverts.
  • New games added over time.
