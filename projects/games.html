Games

Browser games written to explore the fundamentals of game programming: game loops, collision detection and state management. They run in any browser with no installation required.

Visit live ↗

Twin JavaScript + Python implementations

Each game is implemented twice, following the same structure in both languages. Placing the two versions side by side shows the same logic expressed through the syntax of each language.

Key features

  • Every game implemented twice — JavaScript for the browser, Python alongside — structured identically for side-by-side reading.
  • Pure vanilla JavaScript: no frameworks, no build step, no install.
  • Runs on any device with a browser, including managed Chromebooks.
  • Fully static — no server, no database; game state lives in the browser during play.
  • Deploys on every push via GitHub Pages.
