Schoolwise

Schoolwise presents UK school performance over multiple years rather than as single-year league tables, showing longer-term trajectories and allowing search by postcode on an interactive map.

Visit live ↗

Multi-year trajectories, not leaderboards

A single-year ranking can reflect one unrepresentative cohort. Plotting each school's results across several years indicates consistency. A byte-for-byte raw audit layer in the database allows every displayed figure to be traced back to the government file it originated from.

Key features

  • Multi-year performance trajectories per school, instead of single-year league-table snapshots.
  • Interactive map search by postcode, showing nearby schools with their long-term record.
  • Byte-for-byte raw audit layer: every published figure is traceable to the original source file.
  • Portable Python ingest pipeline that reprocesses each yearly government data release.
  • Open data with no sign-in required; all content is publicly readable.
