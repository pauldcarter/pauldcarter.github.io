Learning apps + turn-based multiplayer, one platform

The platform combines single-player practice applications with a real-time multiplayer game, with live state held in Durable Objects over WebSockets. A single account and shell therefore covers both individual practice and multiplayer sessions.

Key features

  • Mental maths, spelling and story-writing apps for kids, on a single SPA shell with shared sign-in.
  • Real-time multiplayer Perudo over WebSockets, with each game's state held in its own Durable Object.
  • Google sign-in with CSRF-protected OAuth and session cookies.
  • Custom routing in a Python Cloudflare Worker, without a framework, for a small bundle and fast cold starts.
  • No conventional database: Durable Objects hold live state and KV handles persistence.
